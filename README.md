Manage and view active Telegram sessions across devices. Export session strings for use with Pyrogram, Telethon, and other automation frameworks.

## Features

- View all active Telegram sessions
- Export session string for Pyrogram and Telethon
- Copy session from Windows Telegram client
- Test session validity before use
- Session revocation if account is compromised
- Multi-account session management

## FAQ

**What is a session string?**  
A session string allows Pyrogram or Telethon to use your account without re-logging.

**Is this safe?**  
Only use session strings in scripts you fully trust.
